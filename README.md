# Missão Digitação - versão 5

Esta versão aproxima a experiência de jogos educativos de digitação com progressão por fases, mantendo identidade própria.

## Novidades
- mapa com 3 ilhas/fases;
- desbloqueio progressivo;
- classificação de 1 a 3 estrelas por fase;
- medalhas/conquistas;
- sistema de combo;
- mascote e cenário animados;
- trilha visual de progresso;
- música de fundo original gerada pelo navegador com Web Audio;
- botão para ligar/desligar música;
- efeitos sonoros próprios, também gerados no navegador;
- histórico local;
- PPM, precisão e treino recomendado.

## Música
A música NÃO usa arquivos ou faixas de terceiros. Ela é gerada em tempo real pelo navegador por meio da Web Audio API, evitando dependência de material protegido por direitos autorais.

## Como executar
Abra `index.html` em um navegador moderno.

Observação: navegadores exigem uma interação do usuário antes de permitir áudio. A música começa após o primeiro clique/toque.
